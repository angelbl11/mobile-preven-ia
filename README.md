# Mobile Preven IA

Aplicación móvil desarrollada con Flutter para la gestión y prevención de riesgos laborales.

## 🚀 Características

- Autenticación segura con Auth0
- Interfaz de usuario moderna y responsiva
- Soporte para múltiples idiomas
- Visualización de datos con gráficos interactivos
- Generación y visualización de PDFs
- Gestión de archivos y documentos
- Notificaciones y alertas
- Navegación intuitiva con barra de navegación persistente

## 📋 Requisitos Previos

- Flutter SDK >=3.2.3
- Dart SDK >=3.2.3
- Android Studio / Xcode (para desarrollo nativo)
- Git

## 🛠️ Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/mobile-preven-ia.git
```

2. Navega al directorio del proyecto:

```bash
cd mobile-preven-ia
```

3. Instala las dependencias:

```bash
flutter pub get
```

4. Ejecuta el proyecto:

```bash
flutter run
```

## 🏗️ Estructura del Proyecto

```
lib/
├── assets/          # Recursos estáticos (imágenes, lotties, etc.)
├── environments/    # Configuraciones de entorno
├── lib/            # Código fuente principal
├── android/        # Configuración específica de Android
└── ios/           # Configuración específica de iOS
```

## 🛠️ Tecnologías Principales

- Flutter
- Riverpod (Gestión de estado)
- Dio (Cliente HTTP)
- Auth0 (Autenticación)
- Syncfusion (Gráficos y PDFs)
- Freezed (Inmutabilidad y serialización)

## 📱 Plataformas Soportadas

- Android (API 21+)
- iOS

## 🔧 Scripts Útiles

- `make build` - Construye la aplicación
- `make clean` - Limpia la build
- `make test` - Ejecuta las pruebas
- `./update_version.sh` - Actualiza la versión de la aplicación
